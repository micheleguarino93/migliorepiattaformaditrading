# Davanti ai Grafici — sito statico

Sito HTML/CSS/JS pronto per GitHub Pages.

## Pubblicazione
1. Carica tutto il contenuto di questa cartella nella root del repository.
2. In GitHub vai su **Settings → Pages**.
3. Seleziona **Deploy from a branch**, branch `main`, cartella `/ (root)`.
4. Se usi il dominio davantiaigrafici.it, configura il custom domain in GitHub Pages e i DNS del dominio.

## Prima di andare online
- Adatta `privacy/index.html` ai servizi realmente usati.
- Verifica il dominio canonico se non userai davantiaigrafici.it.
- Aggiungi Search Console e analytics solo quando vuoi, aggiornando la privacy.
